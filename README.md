## 🏛 О проекте и миссия сохранения

**Comicsbook.ru Archive & Museum** — это комплексный цифровой архив и музей, созданный для сохранения наследия некогда крупнейшего русскоязычного портала веб-комиксов и мемов **Comicsbook.ru**, функционировавшего в период расцвета культуры яростных комиксов (Rage Comics), демотиваторов и мемов раннего рунета.

После закрытия сайта оригинальный контент оказался под угрозой полного исчезновения. Проект решает следующие ключевые задачи:
* **Глубокая реконструкция**: Извлечение десятков тысяч постов, снимков страниц, оригинальных рейтингов, дат публикаций и древовидных веток комментариев из снимков Internet Archive Wayback Machine, официального сообщества ВКонтакте и архивных тредов.
* **100% автономность (Local-First)**: Мобильное приложение работает полностью автономно без подключения к сети. База данных и сжатая медиатека упакованы внутрь дистрибутива.
* **Современный UX с уважением к истории**: Возможность использовать новейший мобильный клиент на React 19 с плавной виртуализацией списков, либо запустить аутентичный настольный сервер на Flask, в точности повторяющий внешний вид оригинального веб-сайта.

| :--- | :--- |

## 🛠 Технологический стек и спецификации

### 1. Программный стек

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          Клиентские платформы                           │
├────────────────────────────────────┬────────────────────────────────────┤
│     Android Application (SPA)      │     Desktop Local Web Server       │
│  React 19 • Vite 8 • Cordova 15   │    Python 3 • Flask • Jinja2       │
│  React Virtuoso • Oxlint           │    SQLite 3 • Vanilla CSS/JS       │
└────────────────────────────────────┴────────────────────────────────────┘
                                  ▲
                                  │
┌─────────────────────────────────┴───────────────────────────────────────┐
│                    Пайплайн данных и медиа-конвейер                     │
├─────────────────────────────────────────────────────────────────────────┤
│  Wayback Machine CDX API • Requests • BeautifulSoup4 • Playwright       │
│  Pillow (PIL) Image Processing • WebP Compression • Audio Transcoder    │
└─────────────────────────────────────────────────────────────────────────┘
```

* **Frontend SPA**: `React 19.2`, `React DOM 19.2`, `Vite 8.1`, `@vitejs/plugin-react 6.0`.
* **Виртуализация ленты**: `react-virtuoso 4.18` (расчет динамической высоты карточек, бесшовная прокрутка).
* **Мобильный контейнер**: `Apache Cordova 15.0 (Android Engine)`, плагины `cordova-plugin-statusbar`, `cordova-base64-to-gallery`, `cordova-plugin-android-permissions`, `cordova-plugin-ionic-webview`.
* **Локальный бэкенд**: `Python 3.10+`, `Flask`, `urllib3`, `requests`.
* **Линтинг и качество**: `Oxlint 1.69` (сверхбыстрый Rust-based линтер JavaScript/JSX).

### 2. Спецификация форматов медиа

* **Изображения (WebP Compression)**:
  * Все оригинальные файлы комиксов (`.jpg`, `.png`, `.gif`) конвертируются в формат **WebP** с помощью `Pillow` с параметром качества `quality=85`.
  * Данное решение позволило **сократить общий вес медиатеки более чем на 68%** без потери читаемости текстов в комиксах и сохранить исходное разрешение.
* **Аудиодорожки**:
  * Формат: **M4A (AAC)** с оптимизированным битрейтом для компактности и совместимости со стандартными декодерами Android WebView.

## 🔄 Архитектурный пайплайн данных

Полный цикл обработки исторического наследия сайта строится по детерминированной схеме:

```mermaid
flowchart TD
    subgraph Sourcing ["1. Источники данных"]
        WB["Wayback Machine (CDX API)"]
        VK["Архив сообщества VK"]
        PK["Архивы Pikabu"]
    end

    subgraph Scraping ["2. Парсинг и экстракция"]
        SCR1["compile_cdx.py<br/>Поиск URL и снапшотов"]
        SCR2["scrape_ratings.py<br/>Парсинг постов и метаданных"]
        SCR3["scrape_comments.py<br/>Сбор веток комментариев"]
        SCR4["scrape_vk_full_final.js<br/>Парсинг постов VK"]
    end

    subgraph Processing ["3. Обработка и нормализация"]
        CONV["download_comics_webp.py<br/>Pillow WebP (Quality 85)"]
        MERGE["merge_vk_data.py & fix_data.py<br/>Целочисленное хеширование ID"]
        DB[("SQLite: comics.db")]
    end

    subgraph Distribution ["4. Сборка и распространение"]
        JSON["Экспорт data.json<br/>(24k+ оффлайн постов)"]
        VITE["Vite 8 Build<br/>(React 19 SPA)"]
        APK["build_android.py<br/>Cordova + Gradle + Auto-Sign"]
        WEB["app.py<br/>Flask Desktop Web UI"]
    end

    WB --> SCR1 --> SCR2 & SCR3
    VK --> SCR4 --> MERGE
    PK --> MERGE
    SCR2 & SCR3 --> DB
    DB --> CONV
    CONV --> DB
    MERGE --> DB
    DB --> JSON
    JSON --> VITE
    VITE --> APK
    DB --> WEB
```

### Этапы пайплайна:
1. **CDX Индексация (`compile_cdx.py`)**: Формирование карты доступных снимков `comicsbook.ru` в Internet Archive Wayback Machine.
2. **Сбор постов и комментариев (`scrape_ratings.py`, `scrape_comments.py`)**: Многопоточный обход страниц, парсинг заголовков, категорий, рейтинга, оригинальных авторов и древовидных комментариев.
3. **Оптимизация медиа (`download_comics_webp.py`)**: Скачивание оригиналов и потоковая конвертация в WebP с сохранением структуры путей.
4. **Нормализация ID (`merge_vk_data.py`, `fix_data.py`)**: Устранение строковых коллизий (приведение строковых `vk_...` идентификаторов к безопасным Integer-хешам для предотвращения багов сортировки `NaN` в JS-движках).
5. **Оркестрация сборки (`build_android.py`)**: Единый скрипт автоматической сборки React, переноса ассетов, создания Cordova-проекта, компиляции через Gradle и финализации подписанного `.apk`.

## 🚀 Руководство по запуску и сборке

### 1. Требования к окружению
* **Node.js** `>= 18.0.0` и **npm**
* **Python** `>= 3.10`
* **Java Development Kit (JDK)** `17` (для компиляции Android APK)
* **Android SDK** с установленными Build Tools (для сборки через Cordova)

---

### 2. Запуск локального настольного сервера (Flask)
Для просмотра архива в аутентичном веб-интерфейсе 2011 года:

```bash
# Установка зависимостей
pip install Flask requests urllib3 pillow

# Запуск сервера
python app.py
```
Откройте браузер по адресу: `http://127.0.0.1:5000`.

---

### 3. Разработка мобильного фронтенда (React + Vite)
Для запуска и тестирования SPA-интерфейса в браузере:

```bash
cd react_app

# Установка зависимостей
npm install

# Запуск dev-сервера с hot-reload
npm run dev

# Проверка линтером Oxlint
npm run lint
```

---

### 4. Автоматическая сборка Android APK
Для компиляции релизного пакета запустите корневой оркестратор:

```bash
python build_android.py
```

Скрипт автоматически выполнит следующие шаги:
1. Вызовет сборку React фронтенда (`npm run build` в `react_app/`).
2. Экспортирует свежие данные базы `comics.db` в структуру `data.json`.
3. Синхронизирует скомпилированные ассеты и WebP-изображения с каталогом `cordova_app/www/`.
4. Скомпилирует релизный APK через Gradle (`gradlew assembleRelease`).
5. Автоматически подпишет APK релизным ключом и сгенерирует готовый файл `comicsbook-release.apk`.
